## 检验口径规范（2026-09-07 定稿，四口径实验后）
实验脚本 `history/research/dev/all01_dev/chk_neut_order3.py`，结果 `chk_neut_order3.txt`
| 口径 | 做法 | 性质 |
|---|---|---|
| A | 中性化(原始值) → rank | round1~5 旧口径；对裸的极端厚尾比率会离群 |
| **B（主口径）** | **rank → 中性化 → rank** | **信息无损(单调变换, 极值仍排第一)、免疫厚尾、最简洁** |
| C | 去极值(MAD5)+z-score → 中性化 → rank | 业界标准；会截断"多大"的信息，仅在需数值尺度时用 |
| D（交叉验证） | 市值20层内 rank → 行业内 demean → rank | 非参数、完全剥离市值(含非线性)、不依赖线性假设 |

**判定规则: B 与 D 同向且同时过门槛才算有效；A/C 仅参考, 单一口径通过不算数。**

### 门槛修订建议（2026-09-07，据 Round5/6 证据）
日频 |IC|>0.02 对**季度更新**的财报因子过严: 财报因子一年只变 4 次, 日频 IC 的
"有效样本量"远小于天数, 而 IC 本身被稀释。Round6 四口径同为正的 5 个因子
IC 仅 0.010~0.016, 但 IC_IR 0.20~0.32、Calmar 0.25~0.46 —— 已属可用水平。
建议**按因子更新频率分档**:
| 因子类型 | 主判据 |
|---|---|
| 日频量价类 | \|IC\|>0.02 且 IC胜率>0.52 且 Calmar>0.5 |
| **季度财报类** | **IC_IR>0.15 且 四口径同向 且 Calmar>0.5 且 最近年超额>0** |

四口径实测(市值中性后年化超额):
| 因子 | A | B | C | D | 结论 |
|---|---|---|---|---|---|
| net_margin_ttm | **+5.75%** | −0.70% | −2.53% | −2.16% | A离群, BCD一致为负 → 无效 |
| sq_margin | **+8.20%** | −0.37% | −2.29% | −1.88% | 同上 |
| roe_ttm | **+1.26%** | −2.23% | −3.00% | −2.91% | 同上 |
| amt_chg(放量,裸比值) | −25.4% | −24.8% | −25.2% | −24.0% | 四口径一致 → 稳健(信号极强) |
| rev_20d / vol60 / amt_log | −4.1 / −3.2 / +0.4% | −4.0 / −2.8 / +0.6% | −4.0 / −3.2 / +0.4% | −3.2 / −2.2 / +0.7% | 一致 → Round1~4 结论安全 |
| ln_mktcap | −6.9% | +6.3% | +16.3% | −8.6% | **退化检验**(因子与中性化变量共线), 四口径都是噪声, 不可用 |

**为什么不一律去极值**: 极值本身有信息(如放量)。正确做法是 **rank 单调压缩**(保留"谁最大")
而非 clip(截掉"多大")。B 口径同时满足"保留极值信息"与"OLS 稳健"两个诉求 → 定为主口径。
