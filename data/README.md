# data/ —— 外部数据缓存（不入库）

这里放**从联网接口临时拉取**的数据，与代码（`engine/` / `tools/`）分开。
`data/` 下除本文件外**全部被 `.gitignore` 忽略**（`data/*` + `!data/README.md`）。

## 为什么单独放

* 这些数据**都能重新拉**，体积大、时效性强，不适合进仓库
* 与 `engine/*.h5`（面板/因子基础数据，由 `engine/build_*.py` 从本地原始数据生成）性质不同：
  后者是**项目自带的输入**，前者是**外部接口的临时产物**

## 约定

1. 每个数据源建一个子目录或明确前缀（如 `xxx_parts/` 分片 + `xxx.parquet` 合并）
2. **必须支持断点续拉**：分片写完就落盘，中断只丢当前分片
3. 拉取脚本放在 `tools/`，并在脚本头注释里写清：接口名、频率限制、单次行数上限
4. 用完即删，不要长期堆在这里

## 已知的接口限制（踩过的坑，写下来省得下次再试）

| 接口类型 | 限制 | 应对 |
|---|---|---|
| 部分高频接口 | 单次返回有**行数上限**，超了**静默截断**（不报错，数据就少了） | 窗口切细，检测返回行数是否恰好等于上限 |
| 部分接口 | **按小时/按天的调用配额** | 节流要按最严的那档设；失败时**长等重试**，不要 3 次失败就跳过（会空转一整天） |
| 混合类型列 | HDF5（PyTables）存不了 object 混类型列 | 用 **Parquet**（`pyarrow`） |
